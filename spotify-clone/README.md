# Spotify Clone

## Overview
This project is a web application that mimics the functionality of a music streaming service similar to Spotify. It allows users to browse music, view recently played tracks, and manage playlists.

## Features
- Recently Played section
- Made For You recommendations
- Music player with controls
- Responsive design

## Setup Instructions
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/spotify-clone.git
   ```
2. Navigate to the project directory:
   ```
   cd spotify-clone
   ```
3. Open `index.html` in your web browser to view the application.

## File Structure
- `src/assets/images`: Contains image files used in the project.
- `src/css/style.css`: Styles for the application.
- `src/js/app.js`: JavaScript code for functionality.
- `src/index.html`: Main HTML file for the application.
