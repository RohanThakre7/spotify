# Spotify Clone

A responsive web application that replicates the core features and user interface of Spotify's web player.

## Features

### 🎵 Music Player

- Full-featured audio player controls (play/pause, next, previous, shuffle, repeat)
- Progress bar with time tracking
- Volume control with mute option
- Currently playing track information display
- Like/favorite song functionality

### 📱 User Interface

- Responsive sidebar navigation
- Featured content section
- Recently played tracks
- Personalized recommendations ("Made For You")
- User profile and settings menu
- Forward/back navigation buttons

### 📋 Playlist Management

- View all playlists
- Create new playlists
- Access to library
- Quick access to liked songs

### 💎 Premium Features

- Subscription modal with two plan options:
  - Free Plan (Basic features with ads)
  - Premium Plan ($9.99/month)
    - Ad-free listening
    - High-quality audio
    - Unlimited skips
    - Offline mode

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome for icons

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. No additional dependencies required for basic functionality
